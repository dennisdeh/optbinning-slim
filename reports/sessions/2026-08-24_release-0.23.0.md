# 2026-08-24 — release 0.23.0

## Ask

Cut 0.23.0, the first release published by the workflow rather than by hand.

## What changed

| | |
|---|---|
| `optbinning/_version.py` | `0.22.0` → `0.23.0`. Still the single source; `pyproject.toml` reads it as a literal. |
| `CHANGELOG.md` | The `Unreleased` section became `## 0.23.0 (2026-08-24)`. Its intro was rewritten: it had described only the `MDLP` work that first landed in it, and the section had since grown to cover the coverage pass, the `metric_special` dict, the cross-platform CI fixes and the release automation. No new empty `Unreleased` heading was added — the next change adds one. |
| `README.md` | Test and coverage figures re-measured (below). The two `information()` sample transcripts print the live version, so they moved to `0.23.0`. The PyPI badge was left alone: it reads the live version from shields.io and must not become a literal again. |

Nothing in `tests/results/` embeds the version, so no tracked artifact needed
regenerating for the bump.

## Verification

Measured 2026-08-24 on the release tree, Python 3.13.15:

- **`pytest`** — **1110 passed, 0 failed**, 23 warnings, 215 s.
- **`flake8 --select=E9,F63,F7,F82`** — 0.
- **`coverage run --source=optbinning -m pytest`** — 99%, **11,587 statements, 13
  uncovered**. The statement count rose from 11,564 with the scenario-weight
  validation and the `metric_special` work; the 13 uncovered are the same
  unreachable ones the README lists, so no new gap was introduced.
- The version bump was made *before* the run, so
  `test_version_has_a_changelog_section` checked `0.23.0` against the dated
  section rather than the old one.

## Preconditions this release depended on

- CI green on all six cells, first reached on run 24 (`1c758a6`). The `pypi` job
  is gated on the full matrix, so no tag could have published before that.
- The PyPI trusted publisher, registered by the maintainer through the pypi.org
  web UI — there is no API for it. Bound to owner `dennisdeh`, repository
  `optbinning-slim`, workflow `release.yml`, environment `pypi`.
