## Example fixed while converting

Upstream's counterfactual example calls `sklearn.datasets.load_boston`, **removed in
scikit-learn 1.2**, so it cannot run on this fork's floor of `scikit-learn>=1.7`. It was
rewritten against the Boston CSV bundled in this repository
(`tests/data/boston_housing.csv`, loaded via `tests.datasets.load_boston`), which keeps
it offline and reproducible from a clone, and the shown output was regenerated by
actually running it. The README notes that the loader lives in the test package and not
in the installed wheel, so the snippet must be run from the repo root.

The scorecard example still uses `fetch_california_housing`, which downloads on first
use; the README flags that it needs network and that the test suite does not.
